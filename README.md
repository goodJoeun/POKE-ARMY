# Poké Army: 별빛을 찾아서 (프로토타입 v0.1)

> 입대 전날 "군대 가기 싫다"만 중얼거리다 잠든 주인공. 눈을 떠보니 포켓몬이 되어 있고… 이 세계에서도 입대 날이다!

Next.js + TypeScript + React로 만든 2D 군 생활 시뮬레이션 프로토타입입니다.
하루 일과표에 맞춰 부대를 돌아다니고, 선후임·간부와 대화하며, 훈련·작업을 미니게임으로 수행하는
"일과 스케줄 + 관계 + 미니게임" 구조의 생활 시뮬레이션입니다.

## 실행

```bash
npm install
npm run sprites # 포켓몬 이미지 받기 (최초 1회, 저장소에는 포함하지 않음)
npm run anotherred -- "<Another Red의 Graphics 폴더>"  # 어나더 레드 도트(정면·뒷모습·아이콘·걷기 시트)를 영문 이름으로 찾아 적용
npm run dev     # http://localhost:3000
```

## 게임 흐름

1. **타이틀 → 내 방 (오프닝)** — 입대 전날 밤 22시, 사람 모습의 주인공(도트 그래픽)으로 방을 돌아다니며 휴대폰·TV·창문(별똥별) 등을 조사한다.
2. **입영통지서** — 책상 위 통지서를 보고 입영 부대(육군·해군·공군)를 떠올린다. 어떤 포켓몬이 될지는 아직 모른다. 확인 후 침대에서 잠든다.
3. **꿈속 문답 (6문항)** — 수수께끼의 목소리가 질문하고 대답에 반응한다. 리더형 / 성실형 / 분위기메이커형 성향이 쌓이고, 깨어나면 그에 맞는 포켓몬이 되어 있다 (육군 4·해군 4·공군 3종).
4. **부대 생활 (12일 = 실제 복무 기간 압축)**
   - 카메라가 주인공을 따라 움직이는 확대 화면(가로 약 16타일)으로 진행한다.
   - 맵 구성: 한 화면이 아니라 길·문으로 이어진 여러 장소를 오간다. 야외 구역은 길 끝(표지판)으로 걸어가면 다음 구역으로 넘어간다.
     - **막사·연병장·농구장** (중심) ↔ **병영식당 앞**(식당 안쪽에 **조리실**) ↔ **분리수거장** / ↔ **PX 앞**(공군은 **BX**) / ↔ **탄약고**(공군 격납고, 해군 함정 부두)**·위병소**(정문 + 사격장·활주로·부두 훈련장)
     - **막사 1층**: 행정반·지휘통제실·정비실·화장실 / 1생활관·세탁실·현관, 복도에 정수기와 게시판
     - **막사 2층**: 휴게실·체단실·도서관·화장실 / 2생활관·싸지방·세탁실, 복도에 정수기와 게시판
     - 복도 게시판: 경계작전명령서, 이번 달 생일자(생일인 사람에게 선물하면 호감 보너스), 식단표, 부대 공지
     문이나 계단 쪽으로 걸어가면 이동한다. NPC도 문과 계단을 따라 여러 방을 거쳐 이동한다 (예: 휴게실 → 계단 → 현관 → 식당).
   - 지휘통제실에서 오늘 근무표(불침번 여부)를 확인하고, 휴게실에서 TV를 볼 수 있다.
   - 주요 NPC 8명 외에 부대 엑스트라 11명(취사병·PX병·의무병·당직부사관·행정병·위병·다른 분대원·구보하는 병사·군견 등)이 군별로 다른 포켓몬으로 등장한다. 말을 걸면 짧은 대사를 하고, 의무병(체력 회복)·군견(멘탈 회복)은 하루 한 번 도움을 준다.
   - 06:10 아침 점호 → 08:30 오전 일과 → 12:00 점심(자유) → 13:30 오후 일과 → 17:30 개인정비(자유) → 21:30 저녁 점호 → 밤 근무: 짝수일 **불침번**(소등 후 자다가 00:00에 이전 근무자가 깨움 → 인수인계 → 근무 → 00:50 다음 근무자를 깨워 교대 → 취침) / 3·7·11일차 **야간 위병소 근무**(23:40 사수·부사수가 조용히 깨움 → 같이 위병소로 → 이전 근무자와 교대 → 00:00~02:00 경계근무 → 같이 복귀) / 5·9일차 **야간 순찰**(손전등을 들고 막사 1·2층 복도·세탁실·화장실을 점검한 뒤 지휘통제실 당직사관에게 보고, 23:00까지)
   - **동행**: 야간 위병소 근무의 사수·부사수, "함께" 하는 퀘스트(동기와 공부·빨래, 후임 안내, 맞선임과 PX 등)의 상대는 내가 걸어온 길을 따라 **바로 한 칸 뒤**에 붙어 다니고, 문도 같이 지난다.
   - **런닝슈즈**(오마주): 전입 첫날 첫 점호가 끝나면 분대장이 신병 보급품으로 런닝슈즈를 건네며 설명서를 읽어 준다. 이걸 받아야 Shift 달리기를 쓸 수 있다.
   - **아침 점호(연병장)**: 전 장병이 구령대를 보고 오와 열을 맞춰 정렬 → 당직사관 구령대 등단 → 분대장 경례·인원 보고 → 국군도수체조 → 애국가 1절 제창 → 병영생활 행동강령 제창(다음 구절 고르기) → 구령 조절 3회(Space 연타로 목소리 크기) → 전달 사항 후 일과 시작.
   - 점호의 모든 절차는 **첫날만** 진행하고, 둘째 날부터는 당직사관(사령)의 마지막 한마디로 끝난다.
   - 밤에는 당직사령과 지휘통제실의 당직병, 위병 외에는 깨어 있는 병력이 없다. 야간 근무 중에는 가끔 **의문의 별빛**(지라치)이 나타나 말을 건다(인간의 기억 +2).
   - **저녁 점호(1생활관)**: 분대원이 침상에 걸터앉아 대기 → 당직사령·당직부관 입실 → 분대장이 "총원·사고·현재원" 인원 보고 → 청소·관물대 점검 → 당직사령의 질문 → 경례 후 퇴실. 분대장이 된 뒤에는 내가 직접 인원 보고를 한다.
   - 식사 시간(점심 12:00~13:00, 저녁)에는 분대원·간부·엑스트라가 모두 식당으로 가서 자기 자리에 앉아 식판을 놓고 먹는다. 아직 밥을 안 먹었으면 배식대에 ❗가 뜨고, 끼니를 거르면 체력 -6·멘탈 -3.
   - **식사도 작전이다**: 이병·일병이고 맞후임이 없으면 식사 시간에 선임(분대장·맞선임·1분대 상병)들을 찾아가 "식사하러 가시겠습니까?"를 여쭤봐야 한다. 여쭌 선임은 막사 앞에서 기다리고, 25분 안에 다 여쭤보면 1생활관이 막사 앞에서 계급순 한 줄로 서서 **다 같이 식당까지 걸어간다**(집합 자리 근처에 있으면 나도 대열에 서서 자동으로 함께 이동)(군기 +2·멘탈 +1·선임 호감 +2씩). 다 못 여쭤봐도 시간이 되면 생활관 인원끼리 알아서 모여 간다(못 여쭌 선임 호감 -1). 맞후임이 생기면 맞후임이 여쭤보고, 다들 막사 앞에 모였다가 알아서 출발한다.
   - 식당에선 배식대에서 식판을 받아 1분대 줄 내 자리에 앉아 **실제로 먹는다**. 앉을 때 **식사 속도를 선택지로 고른다**: 허겁지겁(5분·체력 회복 적음) / 선임 속도에 맞추기(군기↑) / 천천히 꼭꼭(14분·회복 많음, 분대가 먼저 일어나면 눈치). 사람마다 오는 시간·먹는 시간이 달라서 하나둘 들어오고 하나둘 나간다. 1분대는 분대장이 숟가락을 놓으면 차례로 일어난다. 처음 한 번은 맞선임이 **선임 먹는 속도에 맞추는 법**을 귀띔해 준다. 퀘스트 창(Q)에서는 선임·의뢰인·보고 대상의 생김새가 보여서 포켓몬을 몰라도 알아볼 수 있다.
   - **다른 생활관 입실**: 이병·일병은 2생활관 문 앞에서 "(계급) (이름)입니다. 들어가도 되겠습니까?"로 허락을 받아야 한다(그냥 들어가면 군기 -2). 상병부터는 그냥 들어간다.
   - 병영식당엔 배식병 요씽리스, 1생활관엔 1분대 상병, 2생활관엔 2분대 상병·일병·이병이 새로 있다.
   - **시간 흐름**: 기본 실제 1초 = 게임 1분. 점심·저녁 자유 시간에 퀘스트나 식사 집합이 진행 중이면 절반 속도(🐢½)로 흐른다.
   - **퀘스트 창(Q)**: 화면 왼쪽 퀘스트 트래커에 진행 중인 퀘스트의 다음 목적지가 보이고, Q를 누르면 단계별 목적지·소요 시간·보상을 확인할 수 있다.
   - 분대장의 **PX 심부름**은 저녁 개인정비 시간(17:30~21:30)에만 받을 수 있다.
   - 집합은 상단의 "○○까지" 시각(집합 마감)에 판정한다. 그 시각에 해당 구역(실내 장소는 그 방, 야외는 장소 주변)에 있으면 정시에 시작되고, 없으면 지각. 미리 도착하면 "✅ 집합 완료 — 정시 시작 대기"가 표시되며, E로 보고하면 기다리지 않고 바로 시작한다.
   - 집합 시간에 늦으면 지각: 군기·멘탈·분대장 호감 하락 후 강제 이동
   - 3일마다 진급(이병→일병→상병→병장): "…어라!? ○○의 모습이…!" **진화 연출** → 진급 신고 + 계급장 **오버로크** 미니게임
   - 선임 전역 / 후임 전입이 날짜에 따라 일어나며, 7일차부터는 플레이어가 분대장
5. **전역 → 엔딩** — 스탯/호감에 따라 칭호가 갈리고, 잠들면 현실의 **훈련소 첫날 밤**으로 돌아갑니다.

## 시스템

- **스탯**: 체력 / 멘탈 / 군기 / 숙련도 / 돈(계급별 실제 봉급 기준 월급)
- **호감도**: 8명의 NPC(분대장, 맞선임, 동기, 후임 2, 소대장, 행정보급관, 중대장). 상황에 맞는 군대식 응답(관등성명, "시정하겠습니다", 보고 체계, 보안 의식 등)을 해야 호감이 오릅니다.
- **부조리 이벤트**: 선임의 사적 지시 → 정중히 거절 / 따르기 / 마음의 편지. 병영생활 행동강령, 국방헬프콜(1303) 등 실제 제도를 팁으로 안내합니다.
- **군대 상식 도감**: 대화·점호·미니게임에서 얻은 팁이 수첩에 모입니다.
- **시설**: 침상(휴식, 18~21시 휴대폰), 병영식당(식사)·조리실(취사 지원), PX/BX(간식 구매·선물), 싸지방(편지·자격증 공부), 체단실(운동), 도서관(독서), 세탁실(빨래), 정비실(공구 정리), 정수기, 화장실, 농구장, 분리수거장, 탄약고·격납고·부두(둘러보기)
- **연계 퀘스트**: 분대장 인수인계(분리수거 → 정수기 점검 → 인수인계 노트) · 맞선임의 휴가(휴가 신청서 → 책 반납 → 휴가 선물) · 동기의 자격증(공부 → 시험 접수 → 합격 발표) · 후임 적응기(부대 안내 → 농구 → 멘토링) · 소대장의 근무 관리(서류 전달 → 근무 일지 → 근무 결과 보고서). 앞 퀘스트를 끝내면 같은 사람에게 다음 부탁을 받을 수 있고, 체인을 다 마치면 보너스. 부탁이 있는 사람 머리 위엔 💬가 뜨고, 말을 걸면 "부탁 들어보기"로 바로 받는다.
- **장소별 부탁 퀘스트**: 분리수거 당번·정수기 점검(분대장), 책 반납·정비실 공구 반납(맞선임), 빨래 개기(동기), 농구 시합(후임), 생일자 확인(막내), 취사 지원(행정보급관), 근무 일지 전달(소대장). 선임의 사적인 부탁은 정중히 거절해도 불이익이 없다.
- **퀘스트**: 심부름, 서류 전달, 후임 안내, 자격증 공부 등 7종
- **성격 보너스**: 리더형 군기 +30%, 성실형 숙련도 +30%, 분위기메이커형 호감 +30%

## 밸런스 설계

- **군기·숙련도 소프트 캡**: 수치가 높을수록 상승폭이 줄어든다 (`× max(0.2, 1 - 현재값/125)`).
- **군기 해이**: 매일 아침 `(군기 - 40) × 10%`만큼 감소 → 꾸준히 관리해야 유지되는 균형점이 생긴다.
- **피로도**: 일과마다 체력·멘탈 소모 (작업 -12, 훈련 -6~-8, 불침번 -10 / 멘탈 -5~-6). 식사(+15/+2), 수면(+20/+3, 불침번 날 +12)으로 회복.
- **지침 페널티**: 체력 25 미만이면 훈련 점수 -15%, 멘탈 25 미만이면 -10%.
- **숙련도 효과**: 미니게임 기술 재사용 대기시간 최대 -40% (숙련도 100).
- **반복 악용 방지**: 운동·자격증 공부·편지·휴대폰은 1일 1회, 같은 NPC에게 반복 선물할수록 호감 증가량 감소(6→4→2→1).
- 시뮬레이션 기준(12일): 성실 플레이 군기 ~90·모범 전역 / 보통 플레이 군기 ~60·무사 전역 / 방치 플레이 군기 0·상담·의무대 이벤트 후 아슬아슬 전역.

## 코드 구조

```
app/                       Next.js 엔트리 (layout, page, globals.css)
src/game/
  types.ts                 공통 타입
  data/                    군별 설정, 포켓몬, NPC, 대화, 점호 문제, 퀘스트, 일과표, 아이템
  engine/                  타일맵 생성/경로탐색/렌더, 절차적 포켓몬 드로잉 + 선택적 스프라이트, 텍스트 템플릿
  state/store.ts           zustand 게임 상태 (일과 진행, 효과 적용, 저장/불러오기)
  components/              씬(타이틀~엔딩), 월드(캔버스), HUD, 대화창, 메뉴, 수첩, 점호
  minigames/               미니게임 9종 + MinigameHost
```

- 포켓몬 IP는 사용 협의를 거쳐 적용했습니다.
  - 플레이어: 육군(불꽃) 파이리·브케인·아차모·파이숭이 / 해군(물) 꼬부기·리아코·물짱이·팽도리 / 공군(비행) 구구·찌르꼬·불화살빈
  - 성격 분석 점수(리더·성실·분위기메이커)와 각 포켓몬의 성향 가중치를 비교해 가장 잘 맞는 포켓몬이 선택됩니다.
  - NPC(선후임·간부)와 경계근무의 야생 동물도 포켓몬입니다. 목록은 `src/game/data/monsters.ts`, `src/game/data/npcs.ts`에서 바꿀 수 있습니다.
- 포켓몬 이미지는 `npm run sprites`로 PokeAPI에서 받아 `public/sprites/`에 저장합니다 (저작권 때문에 git에는 올리지 않음).
  `npm run anotherred`를 실행하면 포켓몬스터 어나더 레드의 그래픽(Graphics/Pokemon/Front·Back·Icons, Characters/Followers)을 포켓몬 영문 이름(예: CHARMANDER.png)으로 찾아 덮어씁니다.
  필드에서는 걷기 시트, 대화 초상화·미니게임 등 큰 화면에서는 정면/뒷모습 애니메이션이 움직입니다. 이미지가 없으면 캔버스 근사치로 동작합니다.
  공식 에셋으로 교체하는 방법과 키 목록은 `public/sprites/README.md`를 참고하세요.
- 저장은 브라우저 localStorage(하루 시작 시 자동, 침상에서 수동).
- 개발 모드에서는 콘솔에서 `__game.getState()`로 상태를 확인할 수 있습니다.

## 숨은 재미

- 곳곳에 포켓몬 팬이라면 알아볼 만한 오마주가 숨어 있다. (입대 전날 방의 TV와 게임기, 꿈속 목소리, 진급 신고, 의무병, 조리실, 경계근무, 게시판, 수첩의 도감 평가 등)
- 더 많은 오마주: 정수기의 "시원한 물", 식사 시간이 아니면 주방 구석에서 자는(길은 막지 않는) 잠만보 취사병, 해군 중대장 갸라도스의 "분노의 호수" 시절, 해군 분대장 라프라스의 "금요일 연결동굴" 취미, 이수재의 PC, 상위 1% 꼬렛, 포켓몬센터 회복 멜로디 등.
- 말을 걸면 사람마다 3~7개의 잡담 중에서 고르고, 방금 한 말은 연달아 하지 않는다.
