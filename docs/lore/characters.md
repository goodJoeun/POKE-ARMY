# 등장인물 설정

> 군별 포켓몬은 **육군 / 해군 / 공군** 순서. 표기가 하나면 세 군 공통이다.
> 근무 기간: 분대장 1~3일차 · 맞선임 1~6일차 · 후임 4일차부터 · 막내 7일차부터 · 1분대 상병 1~7일차

---

## A. 주인공과 파트너

### 주인공 — 「{me}」

| 항목        | 설정                                                                                                                                   |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 정체        | 입대 전날 밤 별똥별에 "군대 가기 싫다"고 빈 **인간**. 밀덕(군대 유튜브를 수백 편 본 사람), 포덕(포켓몬 IP를 좋아하는 사람)             |
| 포켓몬      | 꿈속 문답으로 결정 (육군 파이리·브케인·아차모·파이숭이 / 해군 꼬부기·리아코·물짱이·팽도리 / 공군 구구·찌르꼬·불화살빈·나몰빼미·에몽가) |
| 성격        | 겁이 많고 도망치고 싶지만, 아는 건 많아서 막상 닥치면 잘해 낸다                                                                        |
| 성장        | "가기 싫다" → "버텨 보자" → "내 발로 가겠다"                                                                                           |
| 스토리 기능 | 단서를 모으고 추리 정리를 이끈다. 마지막 선택의 주인                                                                                   |
| 대표 독백   | "(유튜브에서 본 그대로다… 근데 왜 내가 포켓몬이지?)" / "(거울 속의 저 얼굴… 나였어.)" / "(가기 싫었던 거 맞아. 그래도… 내 발로 갈래.)" |

### 동기 — 파트너

| 항목        | 설정                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------- |
| 포켓몬      | **고라파덕 / 잉어킹 / 주뱃**                                                                            |
| 겉모습      | 겁 많고 착한 동기. 늘 "우리 오늘도 살아남았다…"고 한다                                                  |
| 정체        | 같은 날 밤 별에 **"엄마 곁을 떠나기 싫다"**고 빈 인간. 인간 이름은 **이준서**                           |
| 비밀        | 주인공보다 기억이 빨리 사라진다. 그래서 자주 머리를 감싸 쥔다 (고라파덕의 두통 오마주)                  |
| 스토리 기능 | 파트너. 추리 정리를 함께하고, 10일차엔 주인공 이름까지 잊는다. 주인공이 그의 기억을 되찾아 줘야 진 엔딩 |
| 관계        | 주인공과 서로 의지한다. 호감이 높을수록 고백이 빨라지고, 기억 회복도 쉬워진다                           |
| 대표 대사   | "너… 가끔 사람처럼 말하더라. 혹시 너도…?" / "이 명찰… 왜 눈물이 나지?" / "…야, 너 맞지?" (진 엔딩)      |

## B. 1분대 (원주민)

### 분대장 — 가디 / 라프라스 / 파비코

- **근무**: 1~3일차 (3일차 밤 전역)
- **성격**: 엄격하지만 속정 깊은 말년 병장
- **스토리 기능**: 1장의 길잡이. 전역 전날 괴담 같은 경고를 남긴다.
- **대표 대사**: "여기 오래 있으면, 원래 뭐였는지 잊어버린다더라. 너는 잊지 마라."
- **연계 퀘스트**: 「분대장 인수인계」. 인수인계 노트에 "D-day 적는 사람은 2분대 병장"이라는 메모가 있다 (단서 연결).

### 맞선임 — 디그다 / 왕눈해 / 딜리버드

- **근무**: 1~6일차
- **성격**: 장난기 많은 상병. 부대 괴담 전문가
- **스토리 기능**: **「별똥별 부대 괴담」** 전달자. 농담처럼 진실을 흘린다.
  - "밤에 도서관 불 꺼지면 글자가 움직인대~"
  - "당직부관 중에 진자 들고 다니는 사람 봤냐? 그거 귀신이래."
- **연계 퀘스트**: 「맞선임의 휴가」. 휴가 선물을 고를 때 "넌 휴가 나가면 제일 먼저 누구 보고 싶냐?"고 묻는다 (기억 +3 이벤트).

### 1분대 상병 — 홍수몬 / 쥬쥬 / 부우부

- **근무**: 1~6일차 (맞선임과 같은 날 떠난다)
- **스토리 기능**: 식사 집합의 선임. 의무병과 친해서 **「수면 기록」** 단서로 이어 준다.
- **대표 대사**: "요즘 이상하게 잠이 쏟아지는 애들이 있더라. 의무병한테 물어봐."

### 후임 — 이브이 / 마릴 / 테일로

- **전입**: 4일차
- **성격**: 열정 넘치는 첫 후임
- **스토리 기능**: 2장부터 등장하는 **평범한 원주민**. "선임님은 왜 맨날 하늘을 보십니까?"라고 물으며 주인공의 이상한 행동을 객관적으로 비춰 준다.
- **연계 퀘스트**: 「후임 적응기」

### 막내 — 토게피 / 쏘드라 / 깨비참

- **전입**: 7일차
- **성격**: 질문 많은 막내
- **스토리 기능**: 배드 엔딩의 복선. 처음 인사할 때 "어… 선임님, 저희 어디서 본 적 있지 않습니까?"라고 한다. 배드 엔딩에선 "내 얼굴을 한 신병"과 같은 자리에 선다.

## C. 간부 (원주민)

### 소대장 — 윈디 / 쥬레곤 / 스왈로 (소위 → 7일차 중위)

- **스토리 기능**: 홀수일 밤 당직사관. 근무 일지 관련 단서를 준다.
- **연계 퀘스트**: 「소대장의 근무 관리」. 근무 결과 보고서를 정리하다 **"자정마다 1분씩 비는 근무 기록"**을 발견한다.

### 행정보급관 — 괴력몬 / 야도란 / 깨비드릴조 (상사)

- **스토리 기능**: 짝수일 밤 당직. 7일차 밤엔 **진짜 당직이 행보관인데, 지휘통제실에 또 다른 "당직부관"이 서 있는** 이벤트의 기준점이 된다.
- **대표 대사**: "오늘 당직부관? 오늘은 나 혼자다. …누굴 봤다고?"

### 중대장 — 리자몽 / 갸라도스 / 피죤투 (대위)

- **스토리 기능**: **기록 보관실(서고) 열쇠**의 주인. 7일차 진급 신고 때, 군기가 높으면 "부대사 원본을 봐도 좋다"며 열쇠를 준다. 낮으면 행정병에게 몰래 빌려야 한다.
- **대표 대사**: "기록은 거짓말을 하지 않는다. 다만 읽는 사람이 겁을 낼 뿐이지."

## D. 엑스트라 중 스토리 관련 인물

### 2분대 말 없는 병장 — 꼬마돌 / 샤크니아 / 니로우

| 항목        | 설정                                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 겉모습      | "……"만 하는 병장. 엄청난 포스 (산 정상의 그 사람 오마주)                                                                          |
| 정체        | **10년 전에 끌려온 인간.** 인간 이름 **강민혁**. 소원은 "아무 데도 가기 싫다"                                                     |
| 비밀        | 10년 전 별 조각 7개를 다 모았지만, 마지막 밤 겁이 나서 소원을 거두지 못했다. 그 뒤로 기억을 잃어 가며 남았다                      |
| 하는 일     | 지휘통제실 근무 일지에 매일 **"별이 질 때까지 D-○"**를 적는다. 다음에 올 인간을 위해 단서를 남겼다 (분리수거장 편지 일부, 일기장) |
| 스토리 기능 | 8일차에 처음 길게 말한다. 진 엔딩 조건을 채우면 마지막 밤 함께 돌아간다                                                           |
| 대표 대사   | "……" / "…나는 겁이 났어. 돌아가면, 다시 가야 하니까." / "너는… 가라. 내 몫까지."                                                  |

### 의무병 — 럭키 / 해피너스 / 럭키

- **스토리 기능**: **「의무대 수면 기록」** 단서 (서브). "매년 이맘때 깨어나지 않는 병사가 한두 명씩 생겨. 기록엔 '수면 이상'이라고만 적혀."
- 진 엔딩 직전, 동기의 기억 회복 퀘스트에서 "추억이 약이야"라는 힌트를 준다.

### 행정병 — 루브도 (세 군 공통)

- **스토리 기능**: 중대장 열쇠를 못 받았을 때의 우회로. 서고 열쇠를 몰래 빌려주는 대신 "그림 모델이 되어 달라"는 부탁 퀘스트.

### 2분대 일병 — 델빌 / 셀러 / 네이티

- **공군 네이티**: 엉뚱한 예언을 하는 일병. 도서관 관리병 네이티오(아래)의 "후배"라고 우긴다.
- 육·해군에선 평범한 원주민이다.

## E. 스토리 전용 인물 (새로 추가)

### 지라치 — 소원의 별

| 항목      | 설정                                                                                                                   |
| --------- | ---------------------------------------------------------------------------------------------------------------------- |
| 등장      | 꿈속 목소리(1일차~) → 11일차 밤 이름을 밝힘 → 12일차 밤 연병장 구령대 위에 내려옴                                      |
| 성격      | 장난기 넘치고 졸린 아이 같은 말투("히히", "~거든?"). 천 년 만에 깨어나서 아직 잠이 덜 깼다. 처음엔 놀리듯 말하다가 뒤로 갈수록 미안함이 묻어난다 |
| 입장      | 소원을 들어준 것을 후회하지 않는다. 다만 주인공이 스스로 답을 찾기를 바란다                                            |
| 대표 대사 | "…좋아. 너로 정했다." / "별이 지기 전까지야. 기억해." / "소원을 거둘래? 돌아가면 넌 내일 아침, 진짜 훈련소에 가야 해." |

### 네이티오 — 도서관 관리병 (세 군 공통, 상병)

| 항목      | 설정                                                                                                                 |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| 등장      | 3일차부터 도서관 카운터                                                                                              |
| 특징      | 한쪽 눈으로 과거를, 다른 쪽 눈으로 미래를 본다는 포켓몬. 하루 종일 창밖 해를 바라본다                                |
| 정체      | 원주민이지만 주인공이 실패하는 미래를 이미 봤다. 그 미래를 바꾸려고 **수수께끼 힌트**를 하루 한 번 준다              |
| 대표 대사 | "…책은 읽는 사람을 고른다." / "젖은 페이지는 마르기를 기다려라. 이틀이면 된다." / "밤의 서가는 낮과 다른 말을 한다." |

### 안농 — 서가의 글자들

| 항목   | 설정                                                                  |
| ------ | --------------------------------------------------------------------- |
| 등장   | 5일차·9일차 야간 순찰 중 불 꺼진 도서관                               |
| 특징   | 고대 문자 모양의 포켓몬 무리. 책장 위에 모여 글자를 만든다            |
| 메시지 | 5일차: "별 · 이 · 지 · 기 · 전 · 에" / 9일차: **"소 원 을 거 둬 라"** |
| 연출   | 손전등을 비추면 흩어지고, 끄면 다시 모인다 (손전등 끄기 조작)         |

### 슬리퍼 — 꿈을 먹는 자 (최종 악역)

| 항목      | 설정                                                                                                                                                                          |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 변장      | **당직부관 중사.** 7·11일차 밤, 지휘통제실이나 위병소 앞에 나타난다                                                                                                           |
| 흔적      | 진자 소리 "똑딱, 똑딱", 둥근 진자 자국, 졸린 공기                                                                                                                             |
| 목적      | 인간들이 소원을 거두지 못하게 해서 꿈(식량)을 지킨다                                                                                                                          |
| 수법      | 별 조각 빼돌리기, 진자 최면, 달콤한 말                                                                                                                                        |
| 대표 대사 | "고생이 많군, 이병. 좀 쉬어. 눈을 감으면 편해져…" / "왜 돌아가? 거기선 또 18개월이야. 여기선 영원히 편하게 지내면 돼." / (패배) "…꿈은 언젠가 깨는 법이지. 다음 별에서 보자." |

### 팬텀 — 거울 속의 그림자 (빌런)

| 항목      | 설정 |
| --------- | ---- |
| 등장      | 5·9일차 밤 야간 순찰 때 막사 화장실. 점검을 마치고 거울(세면대) 쪽을 등지고 돌아서면, 등 뒤 거울 속에 비친다. 돌아보면 사라진다 |
| 정체      | 그림자를 먹는 장난꾸러기 악령. 꿈을 먹는 슬리퍼와는 다른 녀석이지만, 둘 다 인간이 여기 남기를 바란다 |
| 연결      | M-02 「거울 속의 나」 — 거울엔 이미 내 얼굴이 제대로 비치지 않는다. "여기 오래 있으면 그림자부터 없어지거든" |
| 대표 대사 | (5일차, 이름 모름) "키히히… 뒤돌아보지 마. 돌아보면 사라져 줄 테니까." / (9일차) "이름 정도는 알려 줄게. 팬텀. 마지막 밤엔 네 그림자를 나한테 놓고 가." |
| 스프라이트 | `gengar` (94) |

### 엄마 — 인간 세계

- **등장**: 목소리만 나온다 (꿈, 휴대폰 통화, 싸지방 편지)
- **대사 흐름**: "…일어나야지, 늦겠다." (1일차) → "어디 아프니? 아무리 깨워도 안 일어나서…" (4일차) → "괜찮아. 가기 싫으면 싫다고 해도 돼. 근데 엄마는 네가 해낼 거 알아." (11일차)
- 주인공의 마지막 결심을 받쳐 주는 목소리다.

## G. 이름 표기 원칙

- 포켓몬 이름은 게임 내 표기를 따른다 (가디, 고라파덕, 지라치, 네이티오, 안농, 슬리퍼…).
- 인간 이름은 **동기 = 이준서, 말 없는 병장 = 강민혁**. 주인공은 플레이어가 입력한 이름.
- 인간 이름은 단서(명찰·일기·뉴스)를 통해서만 드러나고, 대화에선 늦게 쓴다.
