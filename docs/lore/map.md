# 맵 · 장소 설정

> 이미 구현된 장소에 **스토리 역할(단서)**을 겹치고, 스토리에 꼭 필요한 장소 몇 곳을 **새로 추가**한다.
> 단서 번호(C-xx)는 `missions.md`와 같다.

---

## 1. 전체 구조

```
                         [꿈: 별의 언덕]  ← 밤마다 꿈으로만 간다 (신규)
                                │
 [PX/BX 앞] ── [막사·연병장·농구장] ── [병영식당 앞] ── (아래) [분리수거장]
                    │      │                 └ 병영식당 ─ 조리실
                    │   [막사 1층] ─ 계단 ─ [막사 2층] ─ 계단 ─ [막사 옥상] (신규)
                    │                         └ 도서관 ─ [기록 보관실] (신규, 잠김)
                    │
              [탄약고/격납고/부두 · 위병소] ── 정문 (밤엔 [안개] 연출)
```

- 밤 근무 중 정문 밖 타일에 흰 안개를 덮는다 (반투명 오버레이 + 천천히 흐르는 입자).
- 플레이어가 정문 밖으로 걸어 나가면 화면이 하얘졌다가 **초소 앞으로 되돌아온다.**
- 처음 나갈 때만 이벤트 대사가 나온다. "…나가지 않아도 돼…"
