# 설정집 — 「별이 지기 전에」

> 포켓몬 이등병의 메인 스토리 설정집.
> 불가사의 던전 시리즈(파랑구조대·시간의 탐험대)의 분위기를 참고한 오리지널 스토리.

## 한 줄 요약
입대 전날 밤 "군대 가기 싫다"고 별에 빈 밀덕 청년이 꿈속 포켓몬 부대에서 눈을 뜬다.
별이 지기 전, 12일 안에 도서관·게시판·세탁실 같은 부대 곳곳의 떡밥을 모아 **인간으로 돌아가는 방법**을 찾아야 한다.
같은 밤 끌려온 동기와 함께.
