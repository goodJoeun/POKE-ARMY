# 세계관 설정 — 「별똥별 부대」

> 스포일러 포함 · 제작용 문서

## 1. 한눈에 보기

| 항목 | 설정 |
| --- | --- |
| 무대 | 소원의 별이 만든 꿈속 부대 **「별똥별 부대」** (게임 속 부대 전체) |
| 겉모습 | 평범한 육·해·공군 부대. 포켓몬들이 병사로 복무한다 |
| 실체 | 소원을 빈 사람들의 꿈이 모여 굳어진 세계. 원래 이 세계의 포켓몬(원주민)과, 소원 때문에 끌려온 **인간**이 섞여 산다 |
| 만든 존재 | 천 년에 한 번 깨어나는 소원의 포켓몬 **지라치** (본인도 이런 부대가 생길 줄은 몰랐다) |
| 시간 | **12일 = 18개월 압축.** 하루가 약 1.5개월. 12일째 밤에 별이 진다 |
| 주인공의 목표 | 별이 지기 전에 단서를 모아 **인간으로 돌아가기** |
| 핵심 주제 | "도망치고 싶은 마음"을 인정하고, **내 발로 다시 걸어가는 용기** |

## 2. 별똥별 부대가 생긴 이유

1. 천 년에 한 번, 소원의 별 **지라치**가 깨어나 하늘을 가로지른다.
2. 그날 밤 별을 본 사람들의 소원이 지라치에게 닿는다.
3. 그런데 **"군대 가기 싫다"** 같은 소원은 그대로는 이뤄질 수 없다. 내일 아침 입대는 이미 정해진 현실이기 때문이다.
4. 지라치는 소원을 비틀어서 들어준다. **"그럼 인간인 네가 아니라, 포켓몬인 네가 대신 가면 되겠다."**
5. 소원을 빈 사람의 **영혼**은 꿈속 부대로 끌려와 포켓몬이 된다. 어떤 포켓몬이 될지는 꿈속 문답에서 정해진다 (게임 오프닝의 성격 분석).
6. 그 사람의 **인간 몸**은 입대 전날 밤의 침대에서 깨어나지 못하고 잠든다. 현실에선 원인 모를 수면 상태로 병원에 실려 간다.

> 지라치에게 악의는 없다. "도망치고 싶다"는 소원을 가장 다정한 방식으로 들어주려 했을 뿐이다. 그래서 지라치는 끝까지 **답을 강요하지 않고 기다린다.**

## 3. 세계의 규칙

### 규칙 1. 별이 지기 전까지 (12일)
- 지라치의 힘은 깨어 있는 동안만 이어진다. 게임에선 **12일째 밤**, 전역일 밤에 별이 진다.
- 그 전에 **소원을 거두면** 인간으로 돌아간다.
- 거두지 못하면 인간이던 기억이 모두 지워지고, 이 세계의 포켓몬으로 남는다. 다음 별(천 년 뒤)까지 반복되는 부대의 일부가 된다.

### 규칙 2. 소원을 거두는 조건
- **별 조각 7개.** 지라치가 소원을 들어줄 때 흩어진 별빛이다. 부대 곳곳에 떨어져 있고, 큰 사건을 해결할 때 하나씩 모인다.
- **진심.** 마지막 밤 지라치 앞에서 "그래도 내 발로 가겠다"고 스스로 답해야 한다. 별 조각은 목소리를 별에 닿게 하는 도구일 뿐이다.

### 규칙 3. 인간의 기억 (게이지)
- 끌려온 인간은 날마다 인간이던 기억을 조금씩 잃는다.
- 게임에선 **🌟 인간의 기억** 게이지로 보여 준다. 시작은 100이다.

| 변화 | 수치 |
| --- | --- |
| 하루가 지날 때 (2일차부터) | −8 |
| 단서를 찾을 때 | +4 |
| 인간 세계와 닿는 행동 (휴대폰 통화, 인터넷 편지, 꿈) | +3 (하루 1회씩) |
| 추리 정리 성공 | +6 |
| 슬리퍼의 최면에 넘어감 | −10 |

- 기억이 낮아지면 세계가 반응한다.

| 기억 | 연출 |
| --- | --- |
| 50 이하 | 대화 선택지에 "…원래 뭐였더라?" 같은 흐릿한 독백이 섞인다 |
| 30 이하 | 내 인간 이름이 가끔 "???"로 보인다. 화면 가장자리가 흐려진다 |
| 0 | 그 자리에서 **배드 엔딩**이 확정된다 (12일째 밤 연출로 이어짐) |

### 규칙 4. 인간 세계와 닿는 통로
꿈속 부대는 완전히 닫혀 있지 않다. 현실이 새어 드는 틈이 있다.

| 통로 | 새어 드는 것 |
| --- | --- |
| 꿈 | 지라치의 목소리, 입대 전날 밤 내 방의 기억 |
| 거울 (화장실) | 1초 동안 비치는 인간의 내 모습 |
| 싸지방 인터넷 편지 | 보낸 날짜가 비어 있는 가족의 편지 |
| 휴대폰 통화 (침상, 18~21시) | 엄마 목소리. 대화가 묘하게 어긋나 있다 ("어디 아프니?") |
| 정비실 라디오 | 병원 심전도 소리, 의사의 목소리 |

### 규칙 5. 부대의 경계 — 안개
- 위병소 정문 밖은 끝없는 **흰 안개**다. 한 발 내디디면 다시 초소 안에 서 있다.
- 낮엔 평범한 길처럼 보이지만, 밤 근무 때는 진짜 모습이 드러난다.
- 안개는 꿈의 끝이다. 소원을 거두기 전엔 아무도 나갈 수 없다.

### 규칙 6. 자정의 멈춤
- 지휘통제실 벽시계는 매일 **자정에 1분씩 멈춘다.** 꿈이 하루를 이어 붙이는 순간이다.
- 근무 일지에는 누군가 매일 **"별이 질 때까지 D-○"**라고 적어 둔다. 적는 사람은 2분대 말 없는 병장이다.

### 규칙 7. 원주민 포켓몬
- 부대원 대부분(분대장·맞선임·간부·엑스트라)은 **이 세계에서 태어난 포켓몬**이다.
- 이들에게 부대는 그냥 자기 삶이다. 인간들이 돌아가도 그들의 부대는 계속된다.
- 그래서 원주민들은 진실을 모른다. 다만 "여기 오래 있으면 원래 뭐였는지 잊는다"는 **괴담**으로 어렴풋이 안다.

## 4. 끌려온 인간들

| 인물 | 끌려온 때 | 소원 | 현재 |
| --- | --- | --- | --- |
| **주인공** | 이번 별 (입대 전날 밤) | "군대 가기 싫다" | 포켓몬이 되어 갓 전입 |
| **동기** | 이번 별 (같은 날 밤) | "엄마 곁을 떠나기 싫다" | 기억이 주인공보다 빨리 사라지는 중 |
| **2분대 말 없는 병장** | 지난번의 메아리 (10년 전) | "아무 데도 가기 싫다" | 소원을 거두지 못해 기억 대부분을 잃음. 말을 잊어 가고 있다 |
| **역대 이병들** | 수백 년간 | 제각각 | 부대사 사진 속에 같은 자리에 서 있다. 대부분 원주민이 되었다 |

> **10년 전 병장은 어떻게 있나?**
> 지라치는 천 년에 한 번 깨어나지만, 꿈속 부대는 그 사이에도 **메아리처럼** 약하게 이어진다. 병장은 지난 메아리 때 끌려와, 돌아갈 기회를 놓치고 남았다. 이번 별이 그에게도 마지막 기회다 (진 엔딩 조건과 연결).

## 5. 슬리퍼와 꿈을 먹는 자들

- **슬리퍼**는 꿈을 먹고 사는 포켓몬이다. 소원이 만든 이 부대는 그에게 끝없는 식량 창고다.
- 인간들이 소원을 거두고 돌아가면 꿈이 사라진다. 그래서 슬리퍼는 그것을 막는다.
- 방해 방법
  - 별 조각을 빼돌려 탄약고·격납고·부두의 잠긴 상자에 숨긴다.
  - 밤에 **당직부관**으로 변장해 지친 병사에게 진자 최면을 건다. "여기선 영원히 편하게 지내면 돼."
  - 인간의 기억을 갉아먹는다 (기억 게이지 감소).
- 흔적: **똑딱, 똑딱** 하는 진자 소리, 바닥의 둥근 진자 자국, 이상하게 졸린 공기.
- 약점: 함께하는 전우와 쌓은 추억. 호감과 군기가 높을수록 최면에 강하다.

## 6. 진실이 드러나는 순서 (플레이어 시점)

1. 나는 원래 인간이다 → 거울, 엄마 목소리
2. 이 부대는 나를 알고 있었다 → 게시판의 내 이름
3. 이 부대는 별(소원)이 만들었다 → 도서관 「별똥별 부대사」
4. 현실의 내 몸은 잠들어 있다 → 싸지방 편지, 라디오
5. 시간 제한이 있다 → 지휘통제실 D-day
6. 동기도 인간이다 → 세탁실 명찰, 동기의 고백
7. 돌아가지 못한 사람이 있다 → 분리수거장 편지, 말 없는 병장
8. 돌아가는 방법 → 안농의 메시지, 병장의 일기
9. 방해하는 자가 있다 → 진자 자국, 가짜 당직부관
10. 별의 정체 → 지라치

## 7. 톤 가이드

- **기본은 군 생활 코미디**다. 스토리는 밤과 단서를 통해 스며들 듯 진행한다.
- 무서움은 **"괴담" 수준**까지만 다룬다. 공포 게임이 되지 않게 한다.
- 슬픔은 **편지·명찰·사진** 같은 물건을 통해 조용히 전한다.
- 오마주는 알아보면 반갑게, 몰라도 이야기가 이해되게 넣는다.
